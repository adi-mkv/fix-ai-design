Three Skills That Fix AI Design

Claude Code and Codex default to the same tired patterns. These skills break that.

A
Adi 3 min read  ·  May 2026

By default, Claude Code and Codex produce the same frontend every time. Inter font, purple-to-blue gradient, cards nested in cards, a glowing accent somewhere. Functional, forgettable, and immediately recognizable as AI output.

Three skills fix this. Each targets a different layer of the problem: visual identity, design sophistication, and motion quality. Run them together and you get output that looks deliberate.

01 / 03

Impeccable

Created by Paul Bakaus (former Google Developer Advocate, creator of jQuery UI), Impeccable is an open-source skill built directly on top of Anthropic's own frontend-design skill. It ships with 23 slash commands — /audit, /polish, /critique, /animate, /bolder, /quieter, and more — plus 27 deterministic anti-pattern rules that tell the model exactly what not to generate. It operates in two modes: brand (marketing, portfolios) and product (app UI, dashboards), since a landing page and a dashboard live by contradictory rules. Works with Cursor, Claude Code, Gemini CLI, and Codex CLI.

↗ impeccable.style ↗ GitHub
INSTALL 
npx skills add pbakaus/impeccable
02 / 03

Taste Skill

Built by Leonxlnx, Taste Skill is the most-starred third-party design skill for frontend on GitHub, sitting at over 18,000 stars. Rather than a single set of rules, it's a suite of 11 specialized variants — including minimalist, brutalist, high-end, and elite modes — with three numeric dials you set at the top of the file: DESIGN_VARIANCE (1–10, centered to asymmetric), MOTION_INTENSITY (1–10, hover to scroll-triggered), and VISUAL_DENSITY (1–10, airy to dense). The agent reads the brief first and infers design direction before generating anything. Framework agnostic across Cursor, Claude Code, Codex, Gemini CLI, v0, and Lovable.

↗ tasteskill.dev ↗ GitHub
INSTALL 
npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"
03 / 03

Emil Kowalski's Skill

Emil Kowalski is a design engineer at Linear and the creator of Sonner, Vaul, and the animations.dev course. His official skill file distills that work into 43 rules across 7 categories: easing selection (ease-out for entrances, custom Bézier over built-in curves), timing windows (150–250ms for micro-interactions, never over 300ms for standard transitions), GPU-only properties (transform and opacity, never width or height), spring physics for organic motion, and accessibility via prefers-reduced-motion. He recommends loading it on a case-by-case basis rather than always-on.

↗ emilkowal.ski/skill
INSTALL 
npx skills add emilkowalski/skill
