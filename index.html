Three skills that fix AI design

Claude Code and Codex fall back on the same patterns. These three skills fix that.

Adi2 min read

Left alone, coding agents produce the same frontend every time: Inter, a purple-to-blue gradient, cards inside cards and a glow somewhere. It works, and it looks generated.

Each skill below covers one layer: design rules, taste and motion.

Design rules

Impeccable

By Paul Bakaus, creator of jQuery UI. It builds on Anthropic's frontend-design skill with 23 commands, such as /audit, /polish and /animate, and 27 rules for what not to generate.

Brand mode is for marketing pages and product mode is for app UI. It works with Claude Code, Codex CLI, Cursor and Gemini CLI.

impeccable.styleGitHub
Install
npx skills add pbakaus/impeccable
Taste

Taste Skill

By Leonxlnx, with variants including minimalist, brutalist and high-end, and three 1–10 dials: DESIGN_VARIANCE, MOTION_INTENSITY and VISUAL_DENSITY.

The agent reads your brief and picks a direction before it builds anything.

tasteskill.devGitHub
Install
npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"
Motion

Emil Kowalski's skill

Emil Kowalski is a design engineer at Linear and made Sonner, Vaul and animations.dev. His skill has 43 rules on easing, timing (150–250 ms for small interactions), animating only transform and opacity, springs and reduced motion.

He suggests loading it when you need it rather than keeping it always on.

emilkowal.ski/skill
Install
npx skills add emilkowalski/skill
